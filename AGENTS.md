# Project rules

- This is "Well Actually", an evidence-based health and fitness website that breaks down research studies in a friendly, myth-busting tone.
- Use plain HTML, CSS and JavaScript only. No frameworks, no build tools.
- Keep code simple and add comments a beginner can follow.
- Use a mobile-first design that also looks good on desktop.
- Headings use a typewriter-style font from Google Fonts; body text uses a clean, readable font.
- Store all brand colours as CSS variables in one place at the top of `style.css`.
- Every page has the same header, navigation and footer.
- The footer always includes: "Educational content, not medical advice."
- Never invent health facts, statistics, study numbers or citations. Use clearly marked placeholders like `[VERIFY: sample size]` instead.
- Before big changes, explain the plan first.
- Never delete files without asking.
